## 🎵 معرفی

**Farghar Tag Editor** یک ویرایشگر آنلاین حرفه‌ای برای تگ‌های موسیقی است که به کاربران اجازه می‌دهد بدون نیاز به نصب هیچ نرم‌افزاری، تگ‌ها و کاور فایل‌های صوتی و ویدیویی خود را ویرایش کنند.

این ابزار با تمرکز بر **تجربه کاربری نیتیو**، **امنیت**، و **سرعت** طراحی شده و تمام پردازش‌ها به صورت محلی در مرورگر کاربر انجام می‌شود.

### چرا Farghar Tag Editor؟

- ✅ **کاملاً رایگان** - بدون هیچ هزینه‌ای
- 🔒 **امن و خصوصی** - تمام پردازش‌ها در مرورگر شما
- 🚀 **سریع و کارآمد** - با لیزی لودینگ و بهینه‌سازی عملکرد
- 📱 **ریسپانسیو** - تجربه عالی در موبایل، تبلت و دسکتاپ
- 🎨 **رابط کاربری مدرن** - طراحی زیبا با حس اپ نیتیو
- 🌐 **بدون نیاز به ثبت‌نام** - استفاده فوری

## ✨ ویژگی‌ها

### ویرایش تگ‌ها
- ویرایش 20 فیلد تگ مختلف
- پشتیبانی از ID3v1 و ID3v2
- خواندن خودکار تگ‌های موجود
- ویرایش گروهی چند فایل هم‌زمان

### مدیریت چند Artwork
- **افزودن چندین کاور** با دسته‌بندی‌های مختلف:
  - Main / Front Cover (کاور اصلی)
  - Back Cover (پشت کاور)
  - Booklet / Inside (بوکلت و صفحات داخلی)
  - Artist (تصویر هنرمند)
  - Other (تصاویر متفرقه)
- **Replace** - جایگزینی کاور موجود
- **Delete** - حذف کاور با تاییدیه
- **Reorder** - تغییر ترتیب کاورها (بالا/پایین)
- پشتیبانی از فرمت‌های JPEG و PNG
- بدون محدودیت تعداد (فقط محدودیت فرمت فایل)

### رابط کاربری پیشرفته
- **Dropdown های سفارشی (Combo Box)** - جایگزین dropdown پیش‌فرض مرورگر
  - طراحی مدرن و زیبا
  - قابلیت جستجو (Searchable)
  - **امکان وارد کردن مقدار دلخواه** (Custom Value)
  - انیمیشن‌های روان
  - پشتیبانی از کیبورد (Escape, Enter)
  - کلیک بیرون برای بستن
- **مدیریت چند Artwork** - پشتیبانی از چندین کاور برای هر فایل
  - **Main / Front Cover** — کاور اصلی
  - **Back Cover** — پشت کاور
  - **Booklet / Inside** — صفحات بوکلت و Artwork داخلی
  - **Artist** — تصویر هنرمند
  - **Other** — تصاویر متفرقه
  - امکان **Add / Replace / Delete / Reorder** برای Artwork ها
  - بدون محدودیت مصنوعی UI (فقط محدودیت فرمت فایل)
- **Modal تایید حذف** - جلوگیری از حذف تصادفی
  - طراحی زیبا با backdrop blur
  - پشتیبانی از کیبورد
  - دو حالت danger و warning
- **ذخیره‌سازی خودکار** - حفظ داده‌ها بعد از رفرش
  - ذخیره در localStorage
  - بازیابی خودکار تگ‌های ویرایش شده
  - تطبیق فایل بر اساس نام و حجم

### دانلود و خروجی
- دانلود تکی فایل‌ها
- دانلود گروهی به صورت ZIP
- تبدیل خودکار به MP3
- نگهداری File objects در حافظه برای دانلود صحیح پس از رفرش

### تجربه کاربری
- لیزی لودینگ کامپوننت‌ها
- اسکلت لودینگ (Skeleton Loading)
- انیمیشن‌های روان و نیتیو
- Touch-friendly برای موبایل
- Safe area support برای دستگاه‌های مدرن
- **Dropdown های سفارشی (Combo Box)** با قابلیت Autocomplete و افزودن مقدار دلخواه
- **تاییدیه حذف** برای جلوگیری از حذف تصادفی
- **ذخیره‌سازی خودکار** در localStorage برای حفظ داده‌ها بعد از رفرش
- **سیستم تم حرفه‌ای** با 4 حالت: Light, Dark, Warm, Cool
  - استفاده کامل از CSS Variables برای تمام رنگ‌ها (30+ متغیر)
  - تغییر تم در تمام بخش‌ها و کامپوننت‌ها (هدر، فوتر، کارت‌ها، فرم‌ها، دکمه‌ها، متن‌ها)
  - هدر و فوتر با رنگ‌های solid (بدون backdrop-filter)
  - سیستم استایل‌دهی سفارشی با CSS خالص (بدون Tailwind)
- **هدر سه بخشی** با پس‌زمینه solid و shadow:
  - سمت راست: تغییر تم با dropdown
  - مرکز: لوگو و نام پروژه + subtitle ریز
  - سمت چپ: دکمه fullscreen + منوی اطلاعات با badges قابل اسکرول
- **دکمه Fullscreen** برای حالت تمام‌صفحه
- **فوتر نیتیو** ساده با دکمه تنظیمات
- **مودال تنظیمات** با قابلیت‌های:
  - Auto-save toggle
  - Confirm before delete toggle
  - Storage usage monitoring
  - Clear all data option

## 🏗 معماری

### Namespace Pattern
تمام کدها در دو namespace اصلی سازماندهی شده‌اند:

1. **`Farghar`** - تعاریف تایپ، ثابت‌ها و اینترفیس‌ها
2. **`FargharTagProcessor`** - توابع پردازش تگ‌ها

### کامپوننت‌ها
هر کامپوننت با پیشوند `Farghar` نام‌گذاری شده و شامل:
- امضای طراح در ابتدای فایل
- کامنت‌های انگلیسی
- تک‌خط‌نویسی (One-liner) برای کلاس‌ها
- SVG آیکون‌های inline (بدون ایموجی)

### State Management
- استفاده از React Hooks (`useState`, `useEffect`, `useCallback`)
- Lazy loading برای کامپوننت‌های سنگین
- Suspense برای مدیریت لودینگ

### Processing Flow
```
1. کاربر فایل را آپلود می‌کند
2. FargharTagProcessor.readTags() تگ‌ها را می‌خواند
3. کاربر تگ‌ها را ویرایش می‌کند
4. FargharTagProcessor.writeTags() تگ‌های جدید را می‌نویسد
5. فایل نهایی برای دانلود آماده می‌شود
```

## 📖 استفاده

### آپلود فایل
1. فایل‌های صوتی/ویدیویی را بکشید و رها کنید (Drag & Drop)
2. یا روی ناحیه آپلود کلیک کنید و فایل‌ها را انتخاب کنید
3. می‌توانید چندین فایل را هم‌زمان آپلود کنید

### ویرایش تگ‌ها
1. روی فایل مورد نظر در جدول کلیک کنید
2. تگ‌های موجود به صورت خودکار بارگذاری می‌شوند
3. فیلدهای مورد نظر را ویرایش کنید
4. برای فیلدهای پیشرفته، روی "Advanced Fields" کلیک کنید
5. برای متن آهنگ و توضیحات، روی "Lyrics & Comments" کلیک کنید

### ویرایش گروهی
1. حداقل 2 فایل آپلود کنید
2. روی "Batch Edit" کلیک کنید
3. فیلدهای مورد نظر را انتخاب کنید
4. مقادیر جدید را وارد کنید
5. روی "Apply changes" کلیک کنید

### مدیریت Artwork ها
1. بخش "Artwork / Covers" را باز کنید
2. نوع کاور را انتخاب کنید (Front Cover, Back Cover, Booklet, Artist, Other)
3. روی "Add" کلیک کنید و تصویر را انتخاب کنید
4. برای تغییر نوع کاور، از dropdown کنار هر کاور استفاده کنید
5. برای جایگزینی، روی آیکون Replace کلیک کنید
6. برای تغییر ترتیب، از دکمه‌های بالا/پایین استفاده کنید
7. برای حذف، روی آیکون Delete کلیک کنید (با تاییدیه)

### دانلود
1. پس از ویرایش، فایل‌های تغییر یافته در بخش "Download Output" نمایش داده می‌شوند
2. برای دانلود تکی، روی دکمه دانلود هر فایل کلیک کنید
3. برای دانلود گروهی، روی "Download ZIP" کلیک کنید

### ساختار کامپوننت‌ها

هر کامپوننت باید:
- با امضای `// Farghar Tag Editor | Designed & Architected by Farghar | Namespace: Farghar` شروع شود
- کامنت‌ها به انگلیسی باشند
- کلاس‌های Tailwind به صورت تک‌خطی نوشته شوند
- از SVG آیکون‌های inline استفاده کند (بدون ایموجی)
- از namespace `Farghar` برای تایپ‌ها استفاده کند

### افزودن کامپوننت جدید

1. فایل جدید را در `src/components/` ایجاد کنید
2. نام فایل را با `Farghar` شروع کنید
3. امضای طراح را در ابتدای فایل اضافه کنید
4. کامپوننت را در `App.tsx` import و استفاده کنید
